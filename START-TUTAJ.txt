========================================================
  REKLAMA GATEWAY - WSZYSTKO PRZEZ DWUKLIK
========================================================

Nie musisz nic wpisywac w konsoli. Po prostu klikaj pliki
po kolei. Numery pokazuja kolejnosc.

--------------------------------------------------------
  KROK 1: kliknij dwa razy:   "1 - INSTALACJA.bat"
--------------------------------------------------------
  - zainstaluje wszystko, co potrzebne,
  - WYGENERUJE Twoje haslo (zapisz je z ekranu),
  - pobierze tunel.
  Zrob to tylko RAZ.

  Potem otworz plik ".env" (np. Notatnikiem) i wpisz adres
  swojego narzedzia, np.:
      UPSTREAM_URL=http://127.0.0.1:3000
  (Jesli nie wiesz - zostaw puste, zobaczysz strone testowa.)

--------------------------------------------------------
  KROK 2: wybierz wersje i kliknij:
--------------------------------------------------------
  "2 - START dla pracownikow.bat"
       -> pojawi sie LINK + HASLO i otworzy sie strona
          z KODEM QR. Wyslij link pracownikom albo pokaz
          im kod QR do zeskanowania telefonem.

  "3 - START prywatny (tylko ja).bat"
       -> dostep wylacznie dla Ciebie, zdalnie z domu
          (przez prywatna siec Tailscale).

  WAZNE: okno, ktore sie otworzy, ZOSTAW OTWARTE.
  Serwer dziala dopoki okno jest otwarte.

--------------------------------------------------------
  KROK 3 (opcjonalnie): zeby wstawal SAM z Windows
--------------------------------------------------------
  "4 - Wlacz autostart (pracownicy).bat"
  "5 - Wlacz autostart (prywatny).bat"
       -> serwer bedzie uruchamial sie sam po wlaczeniu
          komputera i sam wstanie po awarii.
  "Wylacz autostart.bat"  -> cofa autostart.

--------------------------------------------------------
  PODGLAD: kto sie laczyl
--------------------------------------------------------
  "6 - Pokaz kto sie laczyl.bat"
       -> otworzy ladny raport: ile bylo wejsc, logowan,
          jakie adresy, kiedy ostatnio.
